HOI4 Map Editor (Standalone Tool - Preview)
============================================

This Workshop item is a STANDALONE TOOL, not a gameplay mod. It does not
change Hearts of Iron IV and does not need to be enabled in a playset.

WHAT THIS IS
------------
An unofficial, independently developed editor for HOI4 province maps and
state history files (province colors/terrain, state creation and
properties, owners/controllers/cores/claims, resources, buildings,
victory points), with validation, backups, and transactional saves.

HOW TO RUN IT
--------------
1. Subscribe to this Workshop item.
2. Open its item folder in your Steam Workshop content directory, e.g.:
   <SteamLibrary>\steamapps\workshop\content\394360\<this item's ID>\
3. Run "HOI4 Map Editor.exe" directly from that folder. It runs on its
   own; it is not loaded by the game.

WHERE TO GET UPDATES / SOURCE
------------------------------
GitHub: https://github.com/AdriianCOE/hoi4_state_editor
Report issues there. Releases are also published as signed-hash ZIPs
on the GitHub Releases page.
